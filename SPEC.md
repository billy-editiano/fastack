# specification

This project is a monorepo project of some services.


Each service will have their own folder, let's say service-a then the folder name will be service-a, or an api gateway, the folder name should be api-gateway
service-name/
  helm/
    chart/
      ... (actual helm chart files) ...
    values.sample.yaml
  docker-compose.build.yml
  umbrella.yaml
  src/
    app/
      ... (app content) ...
  Dockerfile
  pyproject.toml

more explanation
- svc/helm/chart/ <- this directory is basically generated by the helm cli generator
- docker-compose.build.yml only list service for easiness building the image, so we can just run docker compose -f docker-compose.build.yml build
- umbrella.yaml content will be like this

```yaml
# umbrella.yaml
name: api-gateway
pull_base_images:
  - source: nginx:latest
    retag: mynginx:latest
```

---

based on these criteria, i want you to build these hello world apps by following this structure

- mariadb (simply wrapping mariadb docker iamge, and create our own chart simple)
- app (simple hello world python fastapi app, jsut return hello world)
- worker (simple hello world fastapi app, just return hello world, connected to DB via env variables)

assume these charts / services can be deployed independently.
